# 0.6.2 个人知识库平台 — 设计文档

> 状态：已确认方向（2026-02-27 用户拍板：浏览+编辑创作 / 图谱 P1 / 路径可配置）
> 前置调研：见本文「数据画像」节（全部实测自 `~/Desktop/huyan_wiki`）

## 1. 背景与目标

用户的个人知识库是一个运行 **LLM Wiki v2 知识编译系统**（Karpathy 方法论）的本地仓库，由 AI Agent 持续维护。目前靠 Obsidian / OpenKnowledge 查看，缺少与 AI包工头 工具体系联动的管理入口。

**目标**：在 AI包工头 内新增「知识库」模块，把该仓库的浏览、检索、图谱、编辑纳入统一管理界面。

## 2. 数据画像（实测）

| 层 | 内容 | 规模 |
|---|---|---|
| `wiki/` | 编译后文章（YAML frontmatter：title/date/tags/aliases + 正文 Confidence 标注） | 93 篇 md，18 个主题目录，+2 个 .canvas，+index.md/log.md |
| `wiki/.entities.json` | 知识图谱 | 264 实体（Concept 109 / Pattern 55 / Dataset 43 / Tool 42…）+ 524 条带类型和置信度的关系 |
| `raw/` | 原始资料（**只增不改**） | 10751 文件，2GB（四轨日报管线为主） |
| `memory/` | sessions / working 证据件 | 少量 |

**写入规范（仓库 AGENTS.md，应用必须遵守）**：
- `raw/` 只增不改，禁止删除
- `wiki/` 可增改，**禁止物理删除**（仅标记归档）
- index.md / log.md 簿记由 agent 维护——app 侧编辑**不做自动簿记**，保存后提示用户（避免双写冲突）

## 3. 架构设计

### 3.1 新模块组成

```
src/pages/WikiPage.tsx          # 知识库主页（/wiki 路由，tools.ts 导航「知识库」BookOpen）
src/lib/wiki.ts                 # parseFrontmatter / scanWiki / searchWiki / 统计
src/lib/wikiGraph.ts            # entities.json 解析 → 图数据结构
src/components/WikiGraphView.tsx # P1：实体关系图（复用 JsonGraphView 的缩放/平移经验）
src/components/settings/WikiSection.tsx # 设置：知识库路径
```

### 3.2 布局（沿用岛式 + 既有面板语言）

```
┌──────────────────────────────────────────────┐
│ 工具栏：搜索框 / 视图切换(浏览|图谱|日志) / 新建文章 │
├──────────┬───────────────────────────────────┤
│ 主题树    │  文章列表（标题+tags+confidence+date）  │
│ 18 目录   │ ─────────────────────────────────  │
│ +计数     │  预览/编辑区（复用规则库三模式切换器）     │
└──────────┴───────────────────────────────────┘
```

### 3.3 文件访问策略

- 默认路径 `~/Desktop/huyan_wiki`：capabilities 静态授权（read/write/read-dir/exists/mkdir 五组），走 plugin-fs（性能好）
- 自定义路径：设置页可改（`settings.ts` 存 `wikiPath`）；落在授权范围外时**只读降级**（rawFs 可读）并提示「该路径未获写入授权」
- `raw/`（2GB）**默认不扫描**，提供「显示原始资料」开关按需懒加载

### 3.4 frontmatter 解析

手写轻量 YAML 子集解析器（仅需支持 `key: value`、`- item` 列表、缩进列表三种形态），不引依赖。解析失败回退：标题取文件名、无 tags。

### 3.5 编辑与新建

- 编辑：textarea + MarkdownPreview 分屏（复用规则库三模式：编辑/分屏/预览），**保存保留 frontmatter 原样**，仅正文可改；Confidence 行不动
- 新建：选主题目录 → 生成 frontmatter 模板（title/date/tags）→ 落盘 `<topic>/<标题>.md`（文件名冲突报错不覆盖）
- 删除：**不提供物理删除按钮**（遵守规范）；提供「归档」= frontmatter 加 `archived: true` + 列表置灰

## 4. 分期计划

| 期 | 内容 | 验收 |
|---|---|---|
| **P0 浏览+编辑** | 主题树/文章列表/预览/搜索/frontmatter 面板/编辑保存/新建/归档/路径设置 | 打开 huyan_wiki 93 篇全部可检索可预览；编辑保存后 frontmatter 字节级不变 |
| **P1 知识图谱** | entities.json 可视化：节点按 9 类实体着色、边显示关系类型+置信度、缩放平移、点节点筛选关联文章；log.md 时间线视图 | 264 节点可交互浏览，渲染流畅（≤400 节点 SVG 直绘） |
| **P2 仪表盘** | 主题分布/更新趋势/confidence 分布统计卡片；canvas 文件查看（Obsidian Canvas 只读渲染） | 统计与目录实况一致 |

## 5. 风险与约束

| 风险 | 对策 |
|---|---|
| 误写破坏 agent 维护的簿记（index/log） | app 不自动写 index.md/log.md；保存后 toast 提示「index/log 由 wiki agent 维护」 |
| 自定义路径无写权限 | 只读降级 + 明确提示，不静默失败 |
| frontmatter 格式变体 | 解析器宽容（失败回退），保存时**整段 frontmatter 原样回写**不做重排 |
| entities.json 手改冲突 | 图谱只读，不提供图编辑 |
| 大文件（raw/ 2GB）拖慢 | 默认不碰 raw/；wiki/ 93 篇 frontmatter 预读 < 100ms 级 |
