# AI包工头 UI/UX 全面重设计（0.6.2）

> 状态：方案待确认
> 方向：极简工程风深化（Flat Design + Inter + 高密度密度档）
> 痛点：视觉不够精致 / 操作不顺手 / 一致性差

## 现状问题盘点

### 一致性
- 弹窗各页面手写（MCP 表头筛选弹窗、Skills 合集选择器、规则库历史弹窗…），backdrop/关闭/定位各写各的
- 空态：有的页面是图标+两行字，有的是一行灰字，有的直接空白
- 表格：MCP 表有筛选弹窗+排序，Providers/Prompts/Profiles 只有简单排序，样式细节不一致
- 图标按钮尺寸混用（h-6/h-7/h-8 都有），tooltip 有的有有的没有

### 精致度
- 加载态：部分页面切换白屏或僵硬（缓存已缓解，但无骨架屏过渡）
- 无统一的焦点态（键盘用户看不到 focus ring）
- 页面切换无过渡，生硬
- 状态反馈颗粒度粗（操作成功的 toast 样式单一）

### 操作效率
- 命令面板功能单薄（只有页面导航+主题）
- 各页面高频操作没有快捷键
- 表格批量操作的入口不一致

## 设计方案

### Phase 0：设计基座（共享原语 + 规范）

**`src/components/ui/` 补齐共享组件库**（全部走主题 token，禁用硬编码颜色）：

| 组件 | 说明 |
|---|---|
| `Dialog` | 统一弹窗：backdrop 点击关闭、Esc 关闭、focus 陷阱、标题栏+内容+按钮区结构 |
| `Popover` | 统一浮层：定位（bottom-start 等）、点击外部关闭 |
| `Tooltip` | 统一悬浮提示：延迟 300ms、text-xs |
| `EmptyState` | 空态：图标 + 标题 + 描述 + 可选引导按钮 |
| `Skeleton` | 骨架屏：pulse 动画，页面加载过渡用 |
| `Select` / `Checkbox` / `Tabs` | 表单控件补齐 |
| `PageHeader` | 页面头部：标题 + 描述 + 右侧操作区 |

**规范落地**（写入 AGENTS.md）：
- 控件高度两档：`h-7`（紧凑工具条）/ `h-8`（表单区）
- 图标尺寸两档：`h-3.5`（按钮内）/ `h-4`（独立图标钮）
- 文本梯度：`text-[11px]` 徽标 / `text-xs` 辅助 / `text-[13px]` 正文 / `text-sm` 标题
- 所有过渡 `transition-colors/150ms ease`，禁止 `transition-all`
- 所有可交互元素 `focus-visible:ring-1 focus-visible:ring-ring`
- 可点击元素必须 `cursor-pointer`

### Phase 1：外壳与全局交互

- 页面切换加 120ms 淡入过渡（`@keyframes fadeIn`，respect prefers-reduced-motion）
- 命令面板升级：分组显示（页面/操作/主题）、最近使用置顶、右侧快捷键提示
- 侧栏导航：active 态加左侧 2px 指示条（比纯底色更精致）

### Phase 2：页面骨架统一

所有工具页套用同一骨架：

```
┌────────────────────────────────────┐
│ PageHeader: 标题 + 描述 + 操作区      │
├────────────────────────────────────┤
│ Toolbar: 搜索/筛选/视图切换/主操作    │
├────────────────────────────────────┤
│ Content（空态/骨架/错误三态统一）     │
├────────────────────────────────────┤
│ 状态栏: 统计 + 反馈                  │
└────────────────────────────────────┘
```

- 表格统一为一个 `DataTable` 组件（表头排序+筛选弹窗+行 hover+批量选择）
- 所有弹窗迁移到 `Dialog`
- 所有空态迁移到 `EmptyState`

### Phase 3：逐页打磨清单

- **JSON/JSONL 编辑器**：工具条按钮加快捷键提示（⌘⏎ 格式化等）；错误定位跳转加闪烁高亮
- **Skills**：分组头粘性定位；卡片 hover 微抬升
- **MCP**：agent 列头压缩为图标+tooltip（名称换行问题根治）
- **规则库**：版本标识更明显（颜色区分同步状态）
- **知识库**：三栏宽度可拖拽；图谱工具条合并到视图内悬浮
- **设置**：左侧节导航粘性 + 当前节高亮

## 验证

- 每个 Phase 完成后：tsc 0 + 全部测试通过 + 六套主题逐一截图核对
- 禁止破坏：主题 token 体系、dbx 式无阴影原则、岛式布局骨架

## 分期策略

每个 Phase 独立 commit。Phase 0 是后续一切的地基，先做。
